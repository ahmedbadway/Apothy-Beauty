# Apothy Beauty 🌿

One-page bilingual (AR/EN) marketing site for Apothy Beauty natural hair-care products.
Built with **React + Vite + Tailwind CSS v4 + Motion**.

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
```

## 📁 Asset swap guide

Every asset below already exists as a **placeholder file at its final path**.
To go live, just overwrite the file with the real asset — same name, same place.

| Asset | Path | Size | Status |
| --- | --- | --- | --- |
| Background video | `public/videos/background.mp4` | 1920×1080 (placeholder is 1280×720), H.264, ≤10 MB ideally | 🔄 swap me — animated gradient placeholder |
| Logo | `public/images/logo/logo.png` | 200×60 PNG | 🔄 swap me — text placeholder |
| Hair Oil 100ml photo | `public/images/products/hair-oil-100ml.jpg` | 800×800 JPG | 🔄 swap me — labeled placeholder |
| Hair Oil 50ml photo | `public/images/products/hair-oil-50ml.jpg` | 800×800 JPG | 🔄 swap me — labeled placeholder |
| Derma Roller photo | `public/images/products/derma-roller.jpg` | 800×800 JPG | 🔄 swap me — labeled placeholder |
| Argan icon | `public/images/ingredients/argan.svg` | 64×64 SVG | 🔄 swap me (or keep) |
| Jojoba icon | `public/images/ingredients/jojoba.svg` | 64×64 SVG | 🔄 swap me (or keep) |
| Castor icon | `public/images/ingredients/castor.svg` | 64×64 SVG | 🔄 swap me (or keep) |
| Black Seed icon | `public/images/ingredients/black-seed.svg` | 64×64 SVG | 🔄 swap me (or keep) |
| Rosemary icon | `public/images/ingredients/rosemary.svg` | 64×64 SVG | 🔄 swap me (or keep) |
| Mint icon | `public/images/ingredients/mint.svg` | 64×64 SVG | 🔄 swap me (or keep) |

Placeholders are generated by `scripts/generate-placeholders.js`. To regenerate:

```bash
npm install --no-save sharp ffmpeg-static
node scripts/generate-placeholders.js
```

Notes:
- **Video**: `VideoBackground.jsx` already points at `videos/background.mp4` and
  cross-fades from the animated-gradient fallback once the video can play. The
  current placeholder mp4 is itself a gradient loop, so swapping is seamless.
- **Product photos**: paths are already defined in `src/config/products.js`
  (`image` field). The cards currently render an inline `<ProductPlaceholder>` in
  `src/components/ProductCard.jsx` — swap it for an `<img src={`${import.meta.env.BASE_URL}${product.image}`}>` to use the files.
- **Logo**: replace `<LogoPlaceholder>` in `src/components/Navbar.jsx` with
  `<img src={`${import.meta.env.BASE_URL}images/logo/logo.png`}>`.
- **Ingredient icons**: the section currently uses inline SVGs in
  `src/components/IngredientsSection.jsx`; the standalone files match them and
  can be referenced the same way once real artwork exists.
