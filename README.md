# Apothy Beauty 🌿

One-page bilingual (AR/EN) marketing site for Apothy Beauty natural hair-care products.
Built with **React + Vite + Tailwind CSS v4 + Motion**.

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
```

## 📁 Asset swap guide

Real assets live at the paths below. To replace one, just overwrite the file —
same name, same place.

| Asset | Path | Size | Status |
| --- | --- | --- | --- |
| Background video | `public/videos/background.mp4` | H.264 MP4 | ✅ real (uploaded) — used by `VideoBackground.jsx` |
| Logo | `public/images/logo/logo.png` | 200×60 PNG | 🔄 swap me — text placeholder (navbar still uses inline SVG) |
| Hair Oil 100ml photo | `public/images/products/hair-oil-100ml.jpg` | 800×800 JPG ideal | ✅ real (uploaded) — shown on the card |
| Hair Oil 50ml photo | `public/images/products/hair-oil-50ml.jpg` | 800×800 JPG ideal | ✅ real (uploaded) — shown on the card |
| Derma Roller photo | `public/images/products/derma-roller.jpg` | 800×800 JPG ideal | ✅ real (uploaded) — shown on the card |
| Ingredient photos | `public/images/ingredients/argan.jpg`, `jojoba.jpg`, `castor.jpg`, `black-seed.jpg`, `rosemary.jpg`, `mint.jpg` | JPG | ✅ real (uploaded) — shown as circular thumbnails (inline SVG icon as fallback) |

Placeholders are generated by `scripts/generate-placeholders.js`. To regenerate:

```bash
npm install --no-save sharp ffmpeg-static
node scripts/generate-placeholders.js
```

Notes:
- **Video**: `VideoBackground.jsx` points at `videos/background.mp4` and
  cross-fades from the animated-gradient fallback once the video can play.
- **Product photos**: wired in — `ProductCard.jsx` renders
  `<img src={BASE_URL + product.image}>` using the paths in
  `src/config/products.js`.
- **Logo**: replace `<LogoPlaceholder>` in `src/components/Navbar.jsx` with
  `<img src={`${import.meta.env.BASE_URL}images/logo/logo.png`}>` when the real
  logo file is dropped in.
- **Ingredient images**: wired in — `IngredientsSection.jsx` shows each
  `.jpg` photo in a circular thumbnail with an inline SVG icon behind it as an
  `onError` fallback.
